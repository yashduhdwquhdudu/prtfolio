# E-Commerce Front-End Web Template

A static, responsive storefront built with HTML5, CSS3, JavaScript (ES6), and Bootstrap.

## Features

- Product gallery with responsive Bootstrap grid
- Category filtering for desk, home, and carry products
- Client-side product search
- Add and remove cart items
- Persistent cart state with `localStorage`
- GitHub Pages compatible with no backend required

Open `index.html` directly or deploy the portfolio folder to GitHub Pages.
